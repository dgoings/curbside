# Curbside

Order ahead from your favorite food trucks. Find trucks near you, order and
pay in the app, and get pinged when your food is ready — no line, no waiting.

## Stack

- API: TypeScript / Fastify / Postgres (PostGIS)
- Web: React
- Mobile: React Native
- Infra: AWS (ECS Fargate, RDS, CloudFront), Terraform

## Development

```sh
npm install
npm run dev
```

Tasks for this project are tracked with [Workbook](https://github.com/dgoings/workbook):
`workbook board` or `workbook serve`.
